# آخرین فرکانس | THE LAST FREQUENCY
فیلم/تجربه سینمایی سه‌بعدی رازآلود با HTML و Three.js — ساخته‌شده برای BROTEX STUDIOS.

## اجرا
پس از فعال‌سازی GitHub Pages برای شاخه `main` و پوشه ریشه، این مسیر را باز کنید:
`https://brotex-dev.github.io/Legend/last-frequency/`

## نسخه فعلی
- تایم‌لاین داستانی ۲۰ دقیقه‌ای در هفت فصل
- محیط سه‌بعدی شامل جاده، ایستگاه متروکه، اتاق کنترل، راهرو، بایگانی و اتاق فرستنده
- شخصیت اصلی و موجود سایه‌ای ساخته‌شده به‌صورت رویه‌ای در Three.js
- انیمیشن حرکت، دوربین سینمایی، مه و ذرات، نورپردازی و حلقه‌های سیگنال
- زیرنویس فارسی زمان‌بندی‌شده و کنترل پخش/توقف و صدا
- صدای محیطی الکترونیکی تولیدشده در مرورگر (بدون دیالوگ ضبط‌شده)

## محدودیت شفاف
این نسخه یک انیمیشن/تجربه سه‌بعدی زنده و قابل‌پخش در مرورگر است، نه فایل MP4 از پیش رندرشده. برای صدای بازیگری، موسیقی اختصاصی و کیفیت نهایی سینمایی باید صداگذاری و دارایی‌های هنری مستقل اضافه شوند. برای اجرای ماژول Three.js از طریق وب‌سرور یا GitHub Pages استفاده کنید.
