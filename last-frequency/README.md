# آخرین فرکانس | The Last Frequency

پروژه فیلم سه‌بعدی ترسناک BROTEX STUDIOS با HTML و Three.js.

## اجرا
فایل‌ها از طریق GitHub Pages قابل میزبانی هستند. وارد پوشه `last-frequency` شوید و `index.html` را اجرا کنید؛ برای اجرای محلی بهتر است از یک وب‌سرور ساده استفاده کنید، چون مرورگرها ممکن است import ماژول را از file:// مسدود کنند.

## وضعیت
- صحنه سه‌بعدی افتتاحیه و ایستگاه رادیویی
- نورپردازی، مه، درخت‌ها و حرکت دوربین
- زیرنویس و تایم‌لاین آغازین

این نسخه پیش‌نمایش اولیه است؛ هنوز فیلم کامل ۲۰ دقیقه‌ای، صداگذاری نهایی و تمام هفت سکانس ساخته نشده‌اند.
